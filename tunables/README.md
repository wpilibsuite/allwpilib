# Tunables

Tunables is WPILib's runtime adjustment API for values that robot programs want to expose to dashboards or debug tools. It lets code declare adjustable values, grouped complex objects, and chooser-style selections while routing storage and updates through pluggable backends.

Detailed docs live in the module `doc` directory:
