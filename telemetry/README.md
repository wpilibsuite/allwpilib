# Telemetry

Telemetry is WPILib's output-only API for publishing robot-program data to dashboards, debug tools, and log files. It organizes values with hierarchical tables and routes them through pluggable backends such as NetworkTables, data logging, or mock backends used by tests.

Detailed docs live in the module `doc` directory:

- [Telemetry design](doc/telemetry.md)
- [C++ API](doc/cpp.md)
- [Python API](doc/python.md)
